Integrated How-To

Built-in training
In the moment: keep timing. If the operator backtracks or you mis-tag something, do not stop—capture it and fix it in Review.

30-second start

  1. Enter a study name.
  2. Paste steps (one per line).
  3. Select a video (optional).
  4. Start Study → tap the step you’re observing → Start/End.

Common scenarios

  • Operator goes back → tag as Rework (or note it) → fix cycle assignment in Review.
  • You hit the wrong step → keep going → correct the row in Review.
  • Interruptions → tag as Wait or Walk (or note it) → it becomes visible in Yamazumi.

Quick Help (built-in training)

North Star: Capture reality. Correct structure in Review. Don’t lose the moment.

If the operator goes back to a prior step (previous cycle)

  • Keep timing.
  • Set Work Type to REWORK (or add a note).
  • In Review, edit that row’s Cycle # to the correct cycle.

If you hit the wrong step

  • Don’t delete in the moment.
  • Finish the timing.
  • In Review, edit the Step and (if needed) the Type.

If there’s an interruption

  • Tag as WAIT or WALK.
  • That “waste slice” becomes visible in the Yamazumi.

Lean coaching prompts

  • What condition causes the cycle to become unstable?
  • What’s the next obstacle preventing flow?
  • What experiment can we run by end of shift?
Tip: Use To Step Start / To Step End to quickly snap the video to the current step’s timestamps.
