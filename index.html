Quick FAQ / Training
Open Process Flow Guide
How to run a clean study (60 seconds)
  1. Setup: pick your process + operator, enter takt if you have it. Load video if available.
  2. Record: select a step, then use Start and End. Capture reality—don’t pause to fix names.
  3. If it gets messy: tag the row as Rework/Wait/Walk and keep going.
  4. Review: use Edit to reassign Cycle/Job/Step/Type without changing timestamps.
  5. Yamazumi: each cycle is one column; look for waste stacks and rework spikes.
Definitions (Lean lens)
VA: changes the product/service in a way the customer pays for, done right the first time.
NNVA: needed today, but the customer wouldn’t pay for it (e.g., checks, paperwork).
Wait: time with no progress (machine idle, searching for info, waiting on upstream).
Walk: motion / travel not creating value.
Rework: doing work again because of defects, missed steps, or backtracking.
Other Waste: everything else that doesn’t move value forward.
Troubleshooting (fast fixes)
  • Buttons not responding after an update: hard refresh (iOS Safari: share → reload; or close tab, reopen). On desktop: Ctrl+F5 / Cmd+Shift+R.
  • Review disabled: you need at least one captured step (Start+End) OR load a JSON file.
  • Yamazumi blank: open Review, ensure rows have a Cycle #. If all rows share Cycle 1, you’ll see one bar.
Operator backtracks to a prior step / prior cycle
Keep timing. Tag the step as Rework (or Wait/Walk). In Review, reassign the row to the correct cycle/job (timestamps stay intact).
I hit the wrong step
Don’t delete in the moment. Finish the capture, then use Edit in Review to correct the step name, job, cycle, and work type.
Operator stops mid-step
Capture what happened. If you need two pieces later, use Split (coming next) or add a note and adjust the assignment in Review.
When do I start a new cycle?
Use the cycle tabs as the operator repeats the process. If reality breaks sequence, keep capturing and correct cycle mapping in Review.
What should I classify as Value Add vs Waste?
VA: transforms the product. NNVA: required but non-transforming (setup, paperwork). Walk/Wait/Rework: waste signals instability.
